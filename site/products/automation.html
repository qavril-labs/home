Questions about this module

Can I see what a rule did?

Yes. Every run is logged with the time, the trigger and the result.

Can my developer connect another system?

Yes. Webhooks deliver signed events, and the API documents each event.

How it works

  1. Choose what should start the rule, such as a sale or a late payment.
  2. Choose what should happen, such as a reminder, a task or a posting.
  3. Review the log to see each time the rule ran and what it did.

A typical example

An invoice is 14 days overdue. The rule sends the customer a polite reminder and adds a task for the owner to call them.
